ISSM (Ice-sheet and Sea-level System Model) scripts and setup guides used in the Dr.Nowicki's icelab, created by Yanmei Tian， for running ISSM simulations on the lab's two servers.

## Server guides

- **[ICELAB_SERVER.md](ICELAB_SERVER.md)** — access, environment setup, and running issm jobs on `icelab`
- **[ISMIP_SERVER.md](ISMIP_SERVER.md)** — access, environment setup, and running issm jobs on `ismip`

## Code

- **[scripts_icelab/](scripts_icelab/)** — the icelab simulation pipeline (setup, relaxation, forward run) — see [scripts_icelab/README.md](scripts_icelab/README.md) for the workflow
- **[scripts_ismip/](scripts_ismip/)** — some scripts on `ismip` 
- **[functions/](functions/)** — shared helper functions the scripts import
